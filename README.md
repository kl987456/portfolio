## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/kl987456/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.
